# 🚩 श्री सिद्धिविनायक मंदिर — Shree Siddhivinayak Mandir
### *सर्वसमावेशक मंदिर व्यवस्थापन, देणगी पावती व UPI देणगी प्रणाली*

---

## 📖 Overview

**श्री सिद्धिविनायक मंदिर (Shree Siddhivinayak Mandir)** is a mobile-first, devotional Temple & Mandir management system designed for transparent receipt generation, budget management, karyakarta performance tracking, and direct UPI Vargani payments.

---

## ✨ Features

1. **🚩 Devotional & Auspicious UI**: Traditional deep maroon, saffron, and gold palette featuring Lord Ganesha and Chhatrapati Shivaji Maharaj.
2. **📱 Instant UPI Vargani (वर्गणी भरा 🙏)**:
   - Dynamic real-time UPI QR code generated with user-selected amount.
   - Mobile deep link (**Pay Directly**) supporting Google Pay, PhonePe, Paytm, BHIM, and CRED.
   - 1-click **Copy UPI ID** (`ganjaleshivam720-1@oksbi`) with feedback toast.
   - Post-payment **UTR / Transaction ID submission** for verification.
3. **📜 Auspicious Receipt Generation**:
   - Number-to-words converter in Marathi / English.
   - Double gold border certificate with corner Swastikas (`卐`), digital signatures, and official Mandal stamp.
   - A5 PDF download and 1-click WhatsApp share.
4. **📉 Transparent Expense Manager**: Categorized expense tracking, authorization controls, bill attachments, and printable expense vouchers.
5. **👥 Karyakarta Directory & Leaderboard**: Track member collection performance with granular administrative permissions.
6. **📊 Reports & Accounting**: Category breakdowns, payment mode distribution, and Excel-compatible UTF-8 BOM CSV exports.
7. **🛡️ Audit Trail**: Application-level append-only audit logging for all receipts, expenses, logins, member updates, and UPI submissions.

---

## 🛠️ Architecture & Tech Stack

* **Frontend**: React 19, Vite 6, Lucide Icons, Canvas Confetti, JSPDF, HTML2Canvas, QRCode.
* **Backend**: Node.js (ESM), Express.js, Better-SQLite3 (WAL mode), Multer, JWT, BcryptJS.
* **Database**: Persistent SQLite (`server/data/mandal.db`).

## 🚀 Quick Start (Local Development)

### 1. Backend Setup
```bash
cd server
npm install
npm run dev # or node src/index.js
```

### 2. Frontend Setup
```bash
cd client
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🌐 Production Deployment with Persistent Storage (Render)

This repository includes a turnkey [render.yaml](render.yaml) blueprint configured with a **1GB Persistent Disk**:

1. **Repository Root**: `.`
2. **Runtime**: Docker (Multi-stage [Dockerfile](Dockerfile))
3. **Plan**: `starter` (Required for persistent disk attachment)
4. **Persistent Disk Mount**: `/app/server/data` (Disk Name: `mandal-persistent-data`)
5. **Uploads Path**: `/app/server/data/uploads` (Configured via `UPLOAD_DIR`)
6. **Health Check**: `/api/health`

### Environment Variables
| Variable Key | Description | Example |
| :--- | :--- | :--- |
| `NODE_ENV` | Environment Mode | `production` |
| `PORT` | Server Port | `10000` |
| `JWT_SECRET` | JWT Secret Key | *(Auto-generated by Render)* |
| `MANDAL_UPI_ID` | Centralized UPI ID | `ganjaleshivam720-1@oksbi` |
| `MANDAL_PAYEE_NAME` | Payee Name | `Shree Siddhivinayak Mandir` |
| `UPLOAD_DIR` | Persistent Uploads Directory | `/app/server/data/uploads` |
